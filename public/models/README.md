# Runtime models

Everything here is generated by `npm run models` (`scripts/bake-models.mjs`)
from the downloaded Sketchfab sources in `assets-src/models/`: packs are split
into single props, centred, grounded and scaled to unit height, heavy meshes
are simplified, and all of it is meshopt-compressed with small WebP textures.
Don't edit these files by hand — edit the script and re-run it.

The list the app loads is `lib/models.ts`; authors and licences are in
`data/credits.ts` (shown on `/credits`).
